## 🧑‍💻 How to Run Locally

1. Clone the repo:

    ```bash
    git clone https://github.com/Himanshu-Kumar-2301/fcc-js-sorting-visualizer.git
    ```

2. Navigate into the folder

    ```bash
    cd fcc-js-sorting-visualizer
    ```

3. Open ```index.html``` in your browser.
